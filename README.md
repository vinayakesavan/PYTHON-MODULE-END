                               Python Assignment: Survey Feedback Analyzer
1.overview
This assignment focuses on using python to organize and analyse survey feedback.
It includes text cleaning, counting selected words, and generates summary insights using loops, 
conditional and user defined functions.


2.objectives
•	Create a dictionary of lists containing preloaded survey feedback entries.
•	Collect additional names, feedback, and ratings from the user, and append them to the dictionary.
•	Clean feedback text by removing punctuation, extra spaces, and uppercase letters.
•	Create a function to count how many feedback entries contain a selected word.
•	Calculate the average rating identify the longest feedback comment, and print the list of unique words used across all feedbacks.

3.Topics covered
Dictionary of lists: Preloaded feedbacks
Start the program with the dictionary of lists, preloaded with 10 feedbacks
Adding more feedbacks
•	Asked the user how many additional feedback entries they wanted to add.
•	Collected the name, written feedback, and rating for each new entry.
•	 Used append () to add the new values to the corresponding lists and incremented the serial number starting from 11

Text cleaning
•	Used a for loop to access and clean each feedback.
•	Used replace () to remove the punctuation marks: full stop, comma, exclamation mark, and question mark.
•	Used split () and " “. join () to separate words and join them with single spaces.
•	Used strip () to remove leading and trailing spaces.
•	Used lower () to convert the feedbacks in to lowercase.


Word count insights: User-defined function
•	Created the function count_word_in_feedbacks(word), which takes a word as its input.
•	Used a for loop that Returns how many feedbacks contain that word. 
•	Called the function to display the number of feedbacks containing "good", "poor", and "excellent


Final summary and insights
•	Displayed the final cleaned feedback data dictionary of lists.
•	Calculated the average feedback from all feedbacks.
•	Displayed the feedback with the longest comment.
•	Displayed list of unique words used across all feedbacks.

•	Practised using zip () and sorted () to arrange customer feedback based on ratings, from highest to lowest.



Technologies used
   
Programming language: Python
Concepts: for loops, if conditions, user-defined functions, counters, and dictionary/list operations, replace (), split (), join (), strip (), lower (), append (), update (), sum (), Len (), round (), zip (), sort ()
